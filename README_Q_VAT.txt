GoldShop — VAT สำหรับสัญญาขายฝาก Q

- ผลตอบแทนของสัญญา Q เป็นยอดรวม VAT แล้ว ระบบถอดฐานภาษีและ VAT ออกจากผลตอบแทน
- สูตร VAT = ผลตอบแทนรวม VAT × 7 ÷ 107
- ต่อสัญญา Q: ยอดคำนวณเท่ากับผลตอบแทนรวม VAT
- ไถ่ถอน Q: ยอดคำนวณ = เงินต้น + ผลตอบแทนรวม VAT
- ยอดรับชำระจริงแก้ไขได้ และไม่จำเป็นต้องตรงกับยอดที่ระบบคำนวณ
- ถ้าผลตอบแทนเป็น 0 บาท VAT เป็น 0 บาท และไถ่ถอนชำระเฉพาะเงินต้น
- ระบบบันทึกฐานภาษี อัตรา VAT ยอด VAT และยอดรวมไว้กับธุรกรรม เพื่อพิมพ์ย้อนหลังได้
- รายการต่อสัญญาและไถ่ถอน Q พิมพ์เป็น “ใบเสร็จรับเงิน / ใบกำกับภาษี”
- ใบกำกับภาษีต่อสัญญา Q ใช้เลขที่ใบ Q-RN-xxxxxx และใบไถ่ถอน Q ใช้ Q-RD-xxxxxx
- ใบกำกับภาษี Q ไม่แสดงยอดรับชำระจริง และมีช่องลงชื่อพนักงาน/ผู้รับเงินเพียงช่องเดียว
- สัญญา P ยังคงคำนวณและพิมพ์เอกสารแบบเดิม

แบบพิมพ์สัญญาขายฝาก P/Q
- ไม่แสดงเบอร์โทรศัพท์ลูกค้า ผลตอบแทนต่อเดือน ผลตอบแทนประมาณวันนี้ และยอดไถ่ประมาณ
- แสดงข้อความเงื่อนไขและคำรับรอง 3 ย่อหน้าก่อนส่วนลงลายมือชื่อ

ปรับหน้ารับขายฝากและใบขายทองใหม่
- ช่องวงเงินขายฝากรวมแสดงเป็นกรอบสีเหลือง ตัวเลขสีแดงขนาดใหญ่
- ใบกำกับภาษีขายทองใหม่แสดงราคาทองแท่งขายออก ราคาทองรูปพรรณขายออก และราคาทองรูปพรรณรับซื้อคืนต่อกรัม
- ระบบบันทึกราคาทองทั้ง 3 ค่าไว้กับรายการขาย เพื่อให้การพิมพ์ย้อนหลังใช้ราคาของวันที่ขาย
- ใบกำกับภาษีขายทองใหม่มีช่องลงชื่อผู้รับเงิน

รับซื้อทองเก่า
- ราคาในใบรับซื้อเริ่มจากราคาทองแท่งรับซื้อปัจจุบัน หักแบบสุ่ม 3.50–5.00%
- สุ่มอัตราใหม่หลังยืนยันการรับซื้อแต่ละครั้ง และบันทึกเปอร์เซ็นต์ไว้กับเอกสาร
- ราคาในใบรับซื้อ/รายการคำนวณตามน้ำหนักและเปอร์เซ็นต์ทอง และนำยอดเดียวกันไปพิมพ์เป็นจำนวนเงินในใบรับซื้อ
- เมื่อคลิกช่องราคาในใบรับซื้อ/บาททอง ระบบสุ่มอัตราหัก 3.50–5.00% และคำนวณราคาใหม่ทันที
- เพิ่มจำนวนเงินจ่ายจริง/รายการ แยกจากราคาในใบรับซื้อ/รายการ
- ใบรับซื้อพิมพ์ราคาในใบรับซื้อเป็นจำนวนเงิน และแสดงยอดจ่ายจริงรวมแยกต่างหาก
- ต้นทุนสต็อกทองเก่ายึดจำนวนเงินจ่ายจริง

ระบบแลกทองเก่าเป็นทองใหม่
- เพิ่มเมนู “แลกทองเก่าเป็นทองใหม่” บน Dashboard
- ทำรายการรับซื้อทองเก่าก่อน แล้วส่งข้อมูลลูกค้าไปหน้าขายทองใหม่อัตโนมัติ
- เครดิตทองเก่ายึดจำนวนเงินจ่ายจริง และคำนวณเงินส่วนต่างกับยอดขายทองใหม่รวม VAT
- รองรับลูกค้าชำระเพิ่ม ร้านคืนเงิน หรือไม่มีส่วนต่าง
- ใบกำกับภาษีทองใหม่ยังแสดงยอดขายเต็มและ VAT พร้อมแสดงเครดิตทองเก่า/ยอดส่วนต่าง
- เชื่อมใบรับซื้อทองเก่าและใบขายทองใหม่ด้วยเลขรายการ EXxxxxxx
- พิมพ์ใบสรุปการแลกทองเป็นเอกสารอ้างอิงกลาง

ศูนย์บริหารและตรวจสอบ
- เก็บ workflow การแลกทองตั้งแต่เริ่มงาน แสดงรายการค้าง และยกเลิกย้อนรายการพร้อม Audit Trail
- รองรับยกเลิกรายการแลกทั้งฝั่งขายทองใหม่และรับซื้อทองเก่า พร้อมสถานะ reversal_error หากย้อนบางส่วนไม่สำเร็จ
- ออกใบลดหนี้ CNxxxxxx และใบเพิ่มหนี้ DNxxxxxx โดยอ้างอิงใบกำกับภาษีเดิม พร้อมแบบพิมพ์
- ใช้ระบบเลขเอกสารกลางสำหรับขายทอง รับซื้อทองเก่า ล็อต ขายทองเก่า แลกทอง ตรวจนับ และใบกำกับภาษี Q
- รายงานภาษีรวมขายทองใหม่ ต่อสัญญา/ไถ่ถอน Q ใบลดหนี้ และใบเพิ่มหนี้ ส่งออก CSV ได้
- รายงานเงินสดประจำวันแยกเงินเข้า/ออกและป้องกันการนับเงินส่วนต่างรายการแลกซ้ำ
- ขายทองเก่าหลายรายการให้คู่ค้าในเอกสารเดียว ตัดสต็อกและพิมพ์ใบขายทองเก่า
- ตรวจนับทองใหม่หรือทองเก่าด้วย QR/รหัสสินค้า สรุปของขาดและรายการเกิน โดยไม่ปรับสต็อกอัตโนมัติ
- แก้ workflow แลกทอง: ผูกใบรับซื้อกับ workflow ก่อนเปิดใบพิมพ์ และกู้ข้อมูลจากฐานข้อมูลเมื่อกลับหน้าหรือเปิดขายทองใหม่
- เมื่อเปิดระบบแลกทองอีกครั้ง ระบบกลับเข้าสู่ workflow ที่ยังค้างของผู้ใช้เดิมโดยอัตโนมัติ

หมายเหตุ: การตั้งค่านี้ใช้ VAT แบบรวมในผลตอบแทน อัตรา 7%
