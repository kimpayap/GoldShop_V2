ระบบประวัติและยกเลิกการขาย

หน้าประวัติการขาย
- เปิดจาก Dashboard > ประวัติการขาย หรือปุ่มบนหน้าขายทอง
- ค้นหาจากเลขที่ขาย ชื่อลูกค้า เลขผู้เสียภาษี รหัสสินค้า และรายละเอียดสินค้า
- กรองช่วงวันที่ สถานะ และช่องทางชำระเงิน
- แสดงยอดขาย ค่าธรรมเนียมบัตร ยอดรับชำระ และสถานะ
- เปิดดูสินค้าทุกชิ้นในใบขาย
- พิมพ์ใบเสร็จ/ใบกำกับภาษีเดิมซ้ำได้

ยกเลิกการขาย
- ใช้ได้เฉพาะ Admin / Manager / Owner
- ต้องยืนยันรหัสผ่านและระบุเหตุผลทุกครั้ง
- ไม่ลบข้อมูลการขายเดิม แต่เปลี่ยนสถานะเป็น cancelled
- บันทึกวันเวลา ผู้ยกเลิก และเหตุผล
- คืนสินค้าทุกชิ้นกลับสถานะ in_stock ในธุรกรรมเดียว
- ทำเครื่องหมายความเคลื่อนไหวการขายเดิมเป็น reversed
- เพิ่มความเคลื่อนไหว sale_cancel สำหรับการคืนสินค้า
- ป้องกันการยกเลิกซ้ำและป้องกันคืนสินค้าที่สถานะเปลี่ยนไป
- เอกสารที่พิมพ์หลังยกเลิกมีกรอบแดง "ยกเลิกการขายแล้ว"

ตรวจสอบแล้ว
- Python syntax/import ผ่าน
- ทดสอบค้นหาตามสถานะและบัตรเครดิตผ่าน
- ทดสอบคืนสต็อก Audit Trail และป้องกันยกเลิกซ้ำผ่าน
- ทดสอบเอกสารยกเลิกแสดงเหตุผลและผู้ดำเนินการผ่าน
