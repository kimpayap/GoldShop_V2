ระบบปรับหน้าจออัตโนมัติ

- ตรวจความกว้างและความสูงของหน้าจอ แล้วปรับความหนาแน่นของ UI อัตโนมัติ
- ลดขนาดตัวอักษร ระยะห่าง ปุ่ม ช่องกรอก และความสูงตารางในจอที่มีพื้นที่น้อย
- ใช้กับหน้าต่างทำงานทั้งหมดที่เปิดเต็มหน้าจอผ่านระบบกลาง
- เมนู Dashboard มีแถบเลื่อน จึงเข้าถึงปุ่มด้านล่างได้ทุกขนาดหน้าจอ
- ปุ่มประเภท/รายละเอียด/%ทองในหน้ารับขายฝากขึ้นบรรทัดใหม่อัตโนมัติ ไม่ล้นด้านขวา
- ปรับการเลื่อนด้วยเมาส์และ Trackpad บน macOS ให้ตอบสนองแม้ค่า scroll มีขนาดเล็ก

ผู้ใช้ปรับขนาดระหว่างใช้งานได้
- macOS: Command + - เพื่อลด, Command + + เพื่อเพิ่ม, Command + 0 คืนค่าอัตโนมัติ
- Windows: Ctrl + - เพื่อลด, Ctrl + + เพื่อเพิ่ม, Ctrl + 0 คืนค่าอัตโนมัติ

เวอร์ชันนี้ใช้หน้ารับขายฝากรูปแบบเดิมตามที่เลือกไว้ และคงระบบขายทอง รูปลายทอง
ตัวกรองสินค้า VAT และค่าธรรมเนียมบัตรเครดิตไว้ครบ
