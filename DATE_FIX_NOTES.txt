GoldShop V2 - Thai Date and Pawn Renewal Fix

สิ่งที่แก้ไข
- แสดงวันที่เป็นรูปแบบไทย เช่น 01 มกราคม 2569
- วันที่และเวลาจะแสดง เช่น 01 มกราคม 2569 เวลา 14:05 น.
- ครอบคลุม Dashboard, รับขายฝาก, ต่อดอก, ไถ่ถอน/รายละเอียดตั๋ว,
  รายการหลุดขายฝาก, ประวัติต่อดอก และใบพิมพ์รับขายฝาก
- การต่อดอกบวกเดือนปฏิทินจาก due_date เดิม
  ตัวอย่าง 2026-10-18 + 1 เดือน = 2026-11-18
- รองรับวันสิ้นเดือน เช่น 2026-01-31 + 1 เดือน = 2026-02-28
- ค่าที่เก็บใน SQLite ยังคงเป็น ISO (YYYY-MM-DD) ตามเดิม

ผลการตรวจสอบ
- Syntax/AST ผ่านครบ 24 ไฟล์ Python
- Calendar-month tests ผ่าน
- Thai date formatting tests ผ่าน
- Integration test ของ renew_pawn ผ่าน และยืนยันว่าบันทึก ISO ถูกต้อง

ระบบแก้ไขรายการผิด
- เพิ่มเมนู "แก้รายการผิด" บน Dashboard
- ยกเลิกตั๋วขายฝากโดยเปลี่ยนสถานะเป็น cancelled ไม่ลบข้อมูลเดิม
- ย้อนรายการต่อดอกล่าสุดและคืน due_date เป็นวันก่อนต่อ
- ย้อนการไถ่ถอนและเปิดตั๋วกลับเป็น active
- ใช้ได้เฉพาะ Admin / Manager / Owner และต้องยืนยันรหัสผ่าน
- บังคับระบุเหตุผล พร้อมเก็บ voided_at, voided_by และ void_reason
- ประวัติต่อดอกแสดงสถานะ "ยกเลิกแล้ว" อย่างชัดเจน

Theme และการนำทาง
- เพิ่ม Theme 4 แบบ: แนวทันสมัย, แนวสดใส, แนวดั้งเดิม, แนวหรูหรา
- แต่ละ Theme เปลี่ยนชุดสี ปุ่ม ตาราง พื้นหลัง และตระกูลตัวอักษร
- บันทึก Theme ลง app_settings และใช้ต่อเนื่องเมื่อเปิดโปรแกรมครั้งใหม่
- Dashboard และหน้าทำงานหลักเปิดเต็มหน้าจอหลัง Login สำเร็จ
- เพิ่มปุ่ม "กลับ Dashboard" ในหน้าลูกค้า รับขายฝาก ต่อดอก หลุดขายฝาก
  แก้รายการผิด และตั้งค่าระบบขายฝาก

ตั๋วหลุดขายฝากหลายรายการ
- แตะแถวเพื่อเลือก/ยกเลิกการเลือกได้หลายตั๋ว เหมาะกับหน้าจอสัมผัส
- แสดงจำนวนรายการ เลขตั๋ว และเงินต้นรวมก่อนยืนยัน
- ยืนยันหลายรายการพร้อมกันด้วยปุ่มเดียว
- ตรวจสอบทุกตั๋วก่อนบันทึกแบบ atomic หากมีรายการไม่ถูกต้องจะไม่บันทึกทั้งชุด

การเลือกข้อมูลรับขายฝากและเดือนต่อดอก
- ปุ่มประเภททอง รายละเอียด %ทอง และน้ำหนักที่เลือกเปลี่ยนสีพร้อมเครื่องหมาย ✓
- เมื่อเลือกค่าใหม่ สถานะสีจะย้ายไปยังปุ่มใหม่ และล้างเมื่อเริ่มรายการใหม่
- หน้าต่อดอกเพิ่มช่องกรอกจำนวนเดือนเองและ Touch Keypad
- รับจำนวนเต็ม 1–120 เดือน และยังคำนวณต่อจาก due_date เดิมแบบเดือนปฏิทิน

หน้าไถ่ถอนแยก
- เมนูไถ่ถอนบน Dashboard เปิดหน้าต่างไถ่ถอนโดยเฉพาะ
- ค้นหาและเลือกตั๋ว แสดงเงินต้น ผลตอบแทน และยอดไถ่โดยประมาณ
- กรอกยอดรับจริงผ่าน Touch Keypad พร้อมหมายเหตุและหน้าต่างยืนยัน
- ปุ่มไถ่ถอนจากหน้ารับขายฝากจะเปิดหน้าแยกและเลือกตั๋วเดิมให้อัตโนมัติ
- ใช้รูปแบบวันที่ไทย เปิดเต็มหน้าจอ และมีปุ่มกลับ Dashboard

ระบบใบพิมพ์และข้อมูลกิจการ
- หน้าตั้งค่าเพิ่มชื่อกิจการ ที่อยู่ โทรศัพท์ เลขผู้เสียภาษี ข้อความท้ายใบ
  และขนาดกระดาษ A4/80mm/กระดาษต่อเนื่อง 9x5.5 นิ้ว โดยบันทึกลงฐานข้อมูล
- ใบรับขายฝากใช้ข้อมูลกิจการที่ตั้งค่าและถามพิมพ์หลังบันทึก
- ใบรับเงินต่อดอกแสดงเงินต้น จำนวนเดือน ผลตอบแทน ยอดรับ และวันครบกำหนดใหม่
- ใบรับเงินไถ่ถอนแสดงเงินต้น ยอดรับจริง และหมายเหตุ
- ใบยกเลิกตั๋ว ใบย้อนต่อดอก และใบย้อนการไถ่ถอนแสดงเหตุผลและ Audit Trail
- เอกสารทุกใบใช้วันที่ไทย มีปุ่มพิมพ์ และช่องลงชื่อพนักงาน/ลูกค้า

สูตรผลตอบแทนไถ่ถอน
- ระยะเวลาที่ต้องคิดดอกไม่เกิน 15 วัน คิดผลตอบแทนครึ่งเดือน
- เกิน 15 วัน คิดเต็มเดือนและปัดจำนวนเดือนขึ้นทุก 30 วัน
- หากมีรายการต่อดอกที่ชำระครอบคลุมถึงวันไถ่แล้ว ไม่คิดดอกซ้ำ ชำระเฉพาะเงินต้น
- หน้าไถ่ถอนแสดงจำนวนวันที่คิดดอก ผลตอบแทน เหตุผล และยอดรวม
- บันทึกรายละเอียดการคำนวณลงหมายเหตุธุรกรรมและใบรับเงินไถ่ถอน

ทะเบียนผู้จำหน่าย/คู่ค้าและมาตรฐาน QR Code
- เพิ่มเมนูคู่ค้าบน Dashboard พร้อมหน้าจอเต็มจอและปุ่มกลับ Dashboard
- เก็บรหัสคู่ค้า ประเภท ชื่อกิจการ เลขผู้เสียภาษี ผู้ติดต่อ โทรศัพท์ อีเมล
  ที่อยู่ ข้อมูลธนาคาร หมายเหตุ สถานะ และวันเวลาแก้ไข
- รองรับค้นหา เพิ่ม แก้ไข และเปิด/ปิดการใช้งานโดยไม่ลบประวัติ
- รหัสคู่ค้าสร้างอัตโนมัติรูปแบบ SUP00001
- สินค้าในระบบสต็อกจะใช้ QR Code แทน Barcode
- QR เก็บเฉพาะรหัสสินค้าในรูปแบบ GOLDSHOP:ITEM:<รหัสสินค้า>
  ส่วนราคา น้ำหนัก และสถานะอ่านจากฐานข้อมูลล่าสุด

ระบบรับทองใหม่เข้าสต็อก
- เพิ่มเมนู "รับทองใหม่" บน Dashboard และหน้าทำงานเต็มหน้าจอ
- เลือกผู้จำหน่ายจากทะเบียนคู่ค้า พร้อมเลขใบส่งสินค้า ใบกำกับภาษี
  วันที่เอกสาร ราคาทองอ้างอิง การชำระเงิน และวันครบกำหนด
- เพิ่มรายการประเภท รายละเอียด %ทอง น้ำหนัก จำนวน ต้นทุนทอง ค่ากำเหน็จ
  ส่วนลด VAT ราคาขายแนะนำ และตำแหน่งจัดเก็บ
- คำนวณก่อนภาษี VAT ยอดรวม จำนวนชิ้น และน้ำหนักรวม
- ยืนยันแบบ atomic แล้วสร้างใบรับ GRN และสินค้า ITM แยกรายชิ้น
- สร้าง stock_movement ประเภท stock_in ให้ทุกชิ้น และป้องกันเลขเอกสารคู่ค้าซ้ำ
- พิมพ์ใบรับทองใหม่และป้าย QR Code ของสินค้าทุกชิ้น

QR Code ใบขายฝาก
- ใบรับขายฝากพิมพ์ QR รูปแบบ GOLDSHOP:PAWN:<เลขตั๋ว>
- หน้าค้นหาตั๋วรองรับข้อมูลจากเครื่องสแกน QR และแปลงกลับเป็นเลขตั๋วอัตโนมัติ
- QR เก็บเฉพาะเลขตั๋ว ข้อมูลลูกค้าและยอดเงินไม่ถูกฝังใน QR

แก้ QR และหน้ารับทองใหม่
- รวมไลบรารี qrcode ไว้ในโครงการ แก้ No module named 'qrcode' โดยไม่ต้องติดตั้งเพิ่ม
- ช่องวันที่รับ วันที่เอกสาร และวันครบกำหนดชำระเปิดปฏิทินให้เลือก
- ปฏิทินแสดงชื่อเดือนไทยและปี พ.ศ. แล้วบันทึกลงฐานข้อมูลเป็น ISO
- ประเภท รายละเอียด %ทอง และน้ำหนักเปลี่ยนเป็นปุ่มเลือกเหมือนหน้ารับขายฝาก
- ปุ่มที่เลือกเปลี่ยนสีพร้อมเครื่องหมาย ✓ และย้ายสถานะเมื่อเลือกค่าใหม่
- ปุ่มน้ำหนักรองรับทั้งบาททองและกรัม โดยแปลงเป็นกรัมก่อนบันทึก

ตรวจข้อมูลหน้ารับทองใหม่
- แก้ could not convert string to float เมื่อช่องตัวเลขว่าง
- ตรวจช่องบังคับก่อนคำนวณ ได้แก่ ประเภท รายละเอียด %ทอง น้ำหนัก จำนวน และต้นทุนทอง
- ช่องค่ากำเหน็จ ส่วนลด และราคาขายแนะนำที่ว่างใช้ค่า 0
- แจ้งข้อความภาษาไทยเฉพาะช่องเมื่อข้อมูลไม่ถูกต้อง
- ย้าย focus และเลือกข้อความในช่องที่ผิด หรือย้ายไปกลุ่มปุ่มที่ต้องเลือก
- จำนวนชิ้นต้องเป็นเลขจำนวนเต็มบวก ต้นทุนและน้ำหนักต้องมากกว่า 0
